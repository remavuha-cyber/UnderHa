# PhoneFarm — этап 1: один телефон

Цель этапа: проверить схему на **одном** телефоне фермы.

```
Ваш телефон                     VPS                      Телефон фермы
 ├─ RustDesk (пульт) ─────► hbbs/hbbr (свой сервер) ◄──── RustDesk (агент)
 └─ панель PhoneFarm ─────► panel :8080              ◄──── браузер: «Скачать видео»
```

- **RustDesk** даёт экран телефона фермы и управление им с вашего телефона.
- **Панель PhoneFarm** — «полуживое» приложение: профиль, RustDesk ID, кнопка «Подключиться» и загрузка видео для телефона фермы.

Состав папки:

| Путь | Что это |
|---|---|
| `server/docker-compose.yml` | Всё для VPS: сервер RustDesk + панель (+ HTTPS по желанию) |
| `server/.env.example` | Пример настроек (пароль панели, домен) |
| `server/panel/` | Панель: `server.js` (Node.js, без зависимостей) и `public/` (веб-приложение) |

## Шаг 1. VPS

Подойдёт самый дешёвый: 1 vCPU, 1 ГБ RAM, 20+ ГБ диска, Ubuntu 22.04/24.04 (~$4–6 в месяц). Если видео большие, берите диск побольше: ролики хранятся на VPS, пока вы их не удалите.

Подключитесь по SSH и выполните:

```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh

# 2. Код (если репозиторий приватный — скачайте ZIP с GitHub и загрузите через scp)
git clone https://github.com/remavuha-cyber/UnderHa.git
cd UnderHa/phonefarm/server

# 3. Настройки: обязательно поменяйте PANEL_PASSWORD
cp .env.example .env
nano .env

# 4. Запуск
docker compose up -d

# 5. Ключ сервера RustDesk — понадобится на телефонах
cat rustdesk-data/id_ed25519.pub
```

Откройте порты в фаерволе VPS (и в панели хостера, если там есть свой фаервол):

| Порт | Протокол | Для чего |
|---|---|---|
| 21115–21117 | TCP | RustDesk |
| 21116 | UDP | RustDesk |
| 8080 | TCP | Панель PhoneFarm |
| 80, 443 | TCP | Только если включаете HTTPS |

Если стоит `ufw`:

```bash
ufw allow 21115:21117/tcp && ufw allow 21116/udp && ufw allow 8080/tcp
```

Проверка: откройте `http://IP-VPS:8080` и введите логин/пароль из `.env`. Должен открыться «Профиль 1».

### HTTPS (рекомендуется, можно позже)

Без HTTPS пароль панели идёт по сети открытым текстом. Бесплатный домен можно взять на duckdns.org и направить его на IP VPS. Дальше:

```bash
# в .env: PANEL_DOMAIN=myfarm.duckdns.org и PANEL_BIND=127.0.0.1
ufw allow 80/tcp && ufw allow 443/tcp
docker compose --profile https up -d
```

После этого панель будет на `https://myfarm.duckdns.org`.

## Шаг 2. Телефон фермы

### 2.1. Подготовка Android

1. Сбросить телефон или завести на нём **один** Google-аккаунт, под канал этого профиля.
2. Вставить **свою SIM** с мобильным интернетом (лучший вариант для YouTube) или подключить Wi-Fi.
3. **Блокировка экрана: «Нет» или «Свайп».** С PIN или паролем удалённо не войти.
4. Тайм-аут экрана: 1–2 минуты.
5. Телефон всё время на зарядке.

### 2.2. RustDesk

1. Установить RustDesk для Android: с github.com/rustdesk/rustdesk/releases (файл `...-aarch64.apk`) или из F-Droid.
2. Меню → **Настройки → ID/Relay сервер**:
   - **ID сервер:** `IP-VPS`
   - **Relay сервер:** `IP-VPS`
   - **Key:** содержимое `id_ed25519.pub` из шага 1
3. Вкладка **«Демонстрация экрана»** → **«Запустить службу»** → разрешить запись экрана.
4. Включить разрешения:
   - **Управление вводом** (Accessibility). Без него будет только просмотр.
   - **Передача файлов.**
5. Задать **постоянный пароль**: меню вкладки демонстрации → настройки пароля. Без постоянного пароля каждое подключение придётся подтверждать на самом телефоне.
6. В настройках RustDesk включить **«Запуск при загрузке»**, если в вашей версии есть такой пункт.
7. Записать **ID** телефона (9–10 цифр).

### 2.3. Чтобы Android не выгружал RustDesk

- **Настройки → Приложения → RustDesk → Батарея → «Без ограничений».**
- На Xiaomi/Redmi дополнительно: **Автозапуск → включить**. В «Недавних» закрепите RustDesk замочком.
- На Samsung: **Батарея → Фоновые ограничения**. Убрать RustDesk из «спящих приложений».

## Шаг 3. Ваш (основной) телефон

1. Установить RustDesk и в **ID/Relay сервер** указать **тот же** IP и Key, что на телефоне фермы.
2. Открыть панель `http://IP-VPS:8080` (или ваш HTTPS-домен) → меню браузера → **«Добавить на главный экран»**. Панель станет иконкой, как приложение.
3. В панели: **Профиль 1 → Настройки профиля** → вписать RustDesk ID телефона фермы, канал, заметку → «Сохранить».
4. Нажать **«Подключиться»**. Если RustDesk не открылся по кнопке (зависит от версии), нажмите «Копировать ID» и вставьте ID в RustDesk вручную. Пароль — постоянный пароль из шага 2.2.

## Как залить видео (рабочий процесс)

1. В панели на своём телефоне: **Профиль 1 → «Загрузить видео»** → выбрать ролик из галереи. Он загрузится на VPS.
2. **«Подключиться»** → вы на экране телефона фермы.
3. На телефоне фермы открыть Chrome со ссылкой из панели («Копировать ссылку для телефона», вид `…/#/inbox/p1`). Логин/пароль браузер запомнит после первого раза.
4. Нажать **«Скачать»**. Видео окажется в «Загрузках».
5. Открыть YouTube → **«+»** → выбрать видео → оформить → опубликовать. Загрузка продолжится и при погашенном экране.
6. В панели удалить ролик, чтобы не занимал место на VPS.

Альтернатива шагам 3–4: передача файлов прямо в RustDesk (если она работает в вашей версии на Android). Панель всё равно удобна как очередь роликов по профилям.

## Чек-лист теста (что проверить на одном телефоне)

- [ ] Подключение с основного телефона через мобильный интернет, не из одной Wi-Fi сети.
- [ ] Нажатия, свайпы и ввод текста работают (это проверка Accessibility).
- [ ] **Экран телефона фермы погашен** → подключение → экран просыпается и показывается. Если остаётся чёрным, запишите это: на этот случай есть обходные варианты (см. ниже).
- [ ] Видео из панели скачивается на телефоне фермы и видно в YouTube при выборе файла.
- [ ] Публикация ролика проходит, загрузка не обрывается при погашенном экране.
- [ ] **Shorts → «Зелёный экран»:** скачанное видео видно в галерее при выборе фона; запись (лучше через таймер) идёт через RustDesk; в кадр камеры фермы ничего лишнего не попадает; звук правильный (проверить громкость оригинала и микрофона в редакторе).
- [ ] **Перезагрузить телефон фермы** → удаётся ли подключиться без того, чтобы кто-то нажимал на нём «Разрешить»?
- [ ] Через сутки: телефон всё ещё онлайн в RustDesk.

Пришлите результаты по пунктам. По ним решим, что дорабатывать перед масштабированием.

### Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Не подключается совсем | Проверить порты на VPS (`docker compose ps`, фаервол), совпадение ID-сервера и Key на обоих телефонах |
| Только просмотр, нажатия не работают | Снова включить «Управление вводом» (Accessibility) для RustDesk |
| Чёрный экран при погашенном телефоне | Временно: «Для разработчиков → Не выключать экран при зарядке» + минимальная яркость. Это для теста; на AMOLED так надолго не оставлять |
| После перезагрузки нет трансляции | Android снова спрашивает разрешение на запись экрана. Решаем на этапе 2 (свой агент нажимает «Разрешить» сам) |
| RustDesk пропадает через несколько часов | Батарея «Без ограничений», автозапуск, закрепление в недавних (шаг 2.3) |
